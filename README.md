# VELOOP Rewards Data Analytics

**Portfolio project — Data Analyst Internship Task 01**

This repository contains an analytics blueprint for reviewing simulated VELOOP rewards and user-behavior workbooks. It covers data profiling, event-data quality checks, KPI definitions, a proposed analytical model, dashboard planning, and implementation priorities.

> **Data integrity:** The supplied workbooks describe simulated/fictional data. Do not present findings as actual VELOOP users, earnings, revenue, withdrawals, retention, conversion, or company performance.

## Project scope

- Workbook and sheet profiling, missingness, duplicate checks, and repeated-ID checks.
- Event-data quality and consistency controls.
- KPI catalogue, proposed logical data model, and dashboard requirements.
- Verification register and implementation backlog.
- Starter SQL and Python profiling workflow.

## Important limitations

The supplied workbooks did not include dedicated reward-ledger, wallet-transaction, withdrawal-lifecycle/history, referral-relationship, or support-ticket datasets. KPIs that depend on these sources cannot be calculated reliably until the sources are supplied or the feature status is confirmed. Do not fabricate missing business data.

## Privacy

Original source workbooks are intentionally excluded from this public repository. Do not commit raw user-level datasets, personal-looking fields, credentials, or confidential material.

## Included starter files

- `VELOOP_Analytics_Starter_SQL.sql` — proposed schema and example queries.
- `profile_veloop_data.py` — reusable workbook profiling script.
- `README_VELOOP_Project.txt` — handoff notes and next steps.

The full project pack also contains the detailed Excel workbook, editable report (DOCX), review PDF, and dashboard wireframe image.
